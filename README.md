# 🐳 Docker Fundamentals Lab

A hands-on Docker lab built on a Linux VM to practice core containerization concepts.

---

## 🛠️ What I Practiced

- Pulled images from Docker Hub and ran containers with custom port mappings and environment variables
- Wrote a `Dockerfile` to build a custom image for a sample web application
- Created user-defined bridge networks for inter-container communication
- Mounted Docker volumes to persist data across container restarts
- Wrote a `docker-compose.yml` to spin up a two-container app (web + db)

---

## 🚀 How to Run

```bash
git clone https://github.com/ankit-saini-devops/docker-fundamentals-lab.git
cd docker-fundamentals-lab
docker compose up -d
docker ps
```
